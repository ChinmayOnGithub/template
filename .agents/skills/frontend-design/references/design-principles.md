# Design Principles (Anti-AI Slop)

1. **Information Density over Blank Space**: Professional productivity software shows data clearly and compactly without forcing unnecessary scrolling.
2. **Monospaced Numerics**: All numbers, timestamps, metrics, and tags must use tabular or monospace numerals (`font-mono`) to prevent visual jitter.
3. **Intentional Keyboard Ergonomics**: Display `<kbd>` hotkey shortcuts beside interactive commands.
4. **Deliberate Type Scale**: Restrict heading scales to predefined levels (`display-md`, `headline`, `card-title`, `body`, `caption`).

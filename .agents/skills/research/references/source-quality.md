# Source Quality Hierarchy

When researching technical solutions, evaluate sources in this priority order:

1. **Tier 1 (Highest Confidence)**:
   - Official framework documentation and release notes
   - Source code and pull request discussions in upstream repositories
   - Official RFCs and standards specifications (W3C, TC39, IETF)

2. **Tier 2 (High Confidence)**:
   - Engineering blog posts from foundational teams (Vercel, Cloudflare, Supabase, Anthropic)
   - Benchmark suites with reproducible public repositories

3. **Tier 3 (Evaluate Critically)**:
   - Community articles (Medium, Dev.to)  -  verify date and API currency
   - AI-generated summaries  -  cross-reference with actual source code

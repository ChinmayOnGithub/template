# Product Thinking Skill

Use this workflow whenever the user proposes a new feature, app concept, or major scope change.

## 1. Discovery Checklist
Before writing code, answer these essential questions:
1. **Target User**: Who specifically experiences this problem?
2. **Core Job-to-be-Done (JTBD)**: What is the user trying to accomplish?
3. **Primary Action**: What is the single most important action the user takes on the screen?
4. **Non-Goals**: What are we explicitly NOT doing in this milestone?
5. **Success Criteria**: How will we objectively prove this feature works?

## 2. Artifact Generation
Document the outcome in `docs/product/PRODUCT_BRIEF.md` and `docs/product/USER_STORIES.md`.
Update `SPEC.md` with explicit capabilities and acceptance criteria before implementation begins.
